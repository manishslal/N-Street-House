# Measurement checklist (in priority order)

Take these with a tape. Inches are fine. "Model has" is what the model currently assumes (original artifact, never measured).

| # | Measure | Model has | Why it matters |
|---|---|---|---|
| 1 | Main hall width, wall face to wall face, at mid height | 1'8" (zone) | Biggest visible error; decides every door off it |
| 2 | Width of the existing stair, between walls or rail | 2'3" | Code minimum is 36" |
| 3 | Front wall to the first stair riser | 6'4" | Stairwell and headroom |
| 4 | Floor to floor: top of main floor to top of upstairs floor | 9'4" | Headroom, ceiling height |
| 5 | Ceiling heights (main, upstairs) and which rooms slope | 8'0" flat | Vaulted rooms look very different |
| 6 | Upstairs hall width | 3'11" | Circulation |
| 7 | Every door: width x height (and which way it opens) | 2'0" to 4'2" | Door schedule |
| 8 | Overall width and depth of each room | from original | Furniture fit |
| 9 | Kitchen: aisle width (counter to counter), counter depth, window sill height | 3'8" aisle | Cabinet layout |
| 10 | Bathrooms: tub length, vanity width, toilet to wall | | Fixture clearances |
| 11 | Window sizes and sill heights | | Egress and elevations |
| 12 | Laundry closet width and depth | 3'4" deep | Stacked unit |

Also useful: a photo straight down each hall with the tape visible, and one photo per room from the doorway.
